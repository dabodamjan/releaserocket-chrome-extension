Release Notes Drafter

Open a repository's Releases page on GitHub and click the "Draft release notes" button in the bottom right corner.

Optional. Needed for private repositories, and raises the GitHub API limit from 60 to 5,000 requests per hour. The token is stored only in your browser on this computer and sent only to api.github.com. It is entered only here, in the extension's own popup, and never enters the GitHub page itself. A fine-grained token with read access to contents and pull requests is enough.
